# Lantern v0.13 — Gold Experience

This release changes Lantern from a story reader with audio into a directed story experience.

## Gold Experience changes
- Premise-first story generation: cold open, central question, stakes, escalation, turn, release, afterglow.
- Visual beats and sound cues are generated with each story.
- Listen mode removes the full text and becomes a cinematic visual canvas.
- Listen starts with pathway-specific visual/microcopy while narration buffers.
- Narration uses a two-segment safety buffer before playback, then generates ahead.
- Background score continues under narration and automatically stops after the story.
- Read mode becomes editorial: large hook, paced sections, visual breaks and pull lines.
- Read + Soundscape uses the same editorial treatment with sound.
- Existing Story Distance and pathway architecture remain intact.

## Important
The cinematic visuals in this Alpha are atmospheric CSS treatments plus generated visual direction. They are the player architecture for later real visual assets, not the final art library.
The bundled sound beds remain Alpha placeholders. Final external Alpha should use mastered original/licensed score assets.
